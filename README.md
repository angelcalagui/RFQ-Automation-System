## RFQ Automation System

**An automated Request for Quotation (RFQ) template originally developed using Excel VBA to reduce repetitive tasks, minimize manual formatting, and streamline the preparation of quotation documents. The system helps organize supplier and material information, automate calculations, and generate a consistently formatted RFQ, improving efficiency and reducing manual work during the quotation process.**

## RFQ Automation Workflow

<img
    src="https://raw.githubusercontent.com/angelcalagui/RFQ-Automation-System/main/gallery/excel.PNG"
    alt=""
    width="100%"
  />
  
**1. Select a Supplier
Go to the Monitoring sheet and click cell E13. Select a supplier from the dropdown list. The system will automatically retrieve and populate the corresponding supplier details.**

**2. Review & Update Information and Template
Review the populated supplier and RFQ information, then update all fields highlighted in red. These fields indicate information that requires your attention or confirmation before generating the RFQ. Review and adjust the template as needed to ensure all details are accurate and complete.**

<img
    src="https://raw.githubusercontent.com/angelcalagui/RFQ-Automation-System/main/gallery/Template.PNG"
    alt=""
    width="100%"
  />

**3. Generate Supplier RFQs
Click Generate to automatically create an individual worksheet for each selected supplier. The system applies the required formatting and organizes the RFQ information into separate supplier-specific sheets.**

<img
    src="https://raw.githubusercontent.com/angelcalagui/RFQ-Automation-System/main/gallery/Generated.PNG"
    alt=""
    width="100%"
  />
  
**4. Export to PDF
Click PDF to export the generated supplier worksheets into PDF files. This allows the completed RFQs to be easily shared or sent to suppliers.**

**5. Clean Up Generated Sheets
After the RFQs have been exported, click Delete to remove the generated supplier worksheets from the workbook while keeping the original template and monitoring data intact.**
